# Rea: desarma cualquier app pieza por pieza con Claude Code

Guía gratis en español para instalar **Rea** en Claude Code y usarlo en 4 mensajes: descompilar, iterar,
pedir una sola pieza y respetar la licencia.

Hecho por [Diego Osorio](https://instagram.com/soydiegoosorio).

**[👉 Abrir la guía paso a paso](https://diegodoc1111.github.io/guia-rea/)**

## Fuentes verificadas (29-oct-2026)

- Rea: https://github.com/morluto/rea (licencia MIT, 406.449 estrellas el 29-oct-2026). Instalación como plugin de
  Claude Code: `/plugin marketplace add morluto/rea` y `/plugin install rea@rea` (docs/installation.md del repositorio).
- Rea pide Node.js 22.23.4+, 24.22.1+ o 26.12.1+ (paquete npm `rea-agents` 6.8.0). Node.js LTS vigente: 24.22.2 y 26.13.0 (nodejs.org).
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup. Claude Code requiere plan Pro, Max, Team o Enterprise.
- Uso responsable: el propio Rea es para investigación legal, educación, interoperabilidad y software propio o con autorización (README).

2

Instala Claude Code

Escribe terminal en el buscador de tu computador y ábrela. Pega el comando de tu sistema y dale Enter. No muestra avance mientras descarga: espera a que termine.

WINDOWS
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
MAC
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Cuando termine, cierra la terminal y vuelve a abrirla. Los comandos son los de la página oficial de instalación. ¿Prefieres sin terminal? La app de Claude para el computador trae Claude Code en la pestaña Code.

3

Escribe claude e inicia sesión

Crea una carpeta en Documentos llamada mi-app. Luego, en la terminal:

WINDOWS
Windows PowerShell
cd Documentos\mi-app
claude
MAC
Terminal
cd ~/Documents/mi-app
claude

La primera vez te abre el navegador para entrar con tu cuenta de Claude. Entras, vuelves a la terminal y ya está Claude Code esperando tu mensaje. Si te pide permiso para crear archivos o instalar algo, acéptalo: así trabaja.

4

Instala Node.js (una sola vez)

Rea lo necesita para funcionar. Si ya lo tienes, salta al paso 5. En una terminal nueva:

WINDOWS
Windows PowerShell
winget install OpenJS.NodeJS.LTS
MAC Descargar Node.js para Mac →

En Mac descarga el instalador “LTS” y dale siguiente hasta terminar. Luego cierra la terminal y vuelve a abrirla.

5

Instala Rea dentro de Claude Code

Abre Claude Code (escribe claude en la terminal) y pega estas dos líneas, una por una, con Enter:

Claude Code
/plugin marketplace add morluto/rea
/plugin install rea@rea

Cuando termine, escribe /exit, vuelve a escribir claude y Rea queda conectado. Es el repositorio oficial: github.com/morluto/rea.

Úsalo en 4 mensajes

Pégalos en Claude Code en este orden. Cambia lo que está entre corchetes.

1

Descompilar

La app viene cerrada en unos y ceros

Rea la abre y se la traduce a Claude. No sale el código original: sale en “letra de médico”, pero Claude lo entiende y te lo explica.

mensaje 1
Usa REA para abrir [nombre de la app o la carpeta donde está instalada] y explícame en palabras sencillas cómo funciona [la parte que me interesa]: qué pantallas tiene, qué datos guarda y qué pasa cuando le doy clic a cada botón. Muéstrame la evidencia de cada cosa que me digas.
2

Iterar

Arma, compara y corrige

Claude arma su propia versión, la compara con la original y se corrige una y otra vez hasta que funciona casi igual.

mensaje 2
Ahora arma tu propia versión de [esa parte] en esta carpeta, escrita desde cero. Pruébala, compárala con la original, anota las diferencias y corrígelas. Repite hasta que funcione casi igual y dime qué quedó distinto.
3

Una sola pieza

No rehaces toda la app

Pides solo lo que usas y dejas de pagar por botones que nunca tocas. Ejemplo: “de mi CRM solo quiero el seguimiento de leads”.

mensaje 3
De [nombre de la app] solo quiero [el calendario]. Usa REA para entender cómo funciona esa parte y constrúyeme solo esa pieza, lista para usarla en mi negocio. Lo demás no lo necesito.
4

Licencia

El código de otros tiene dueño

En el video va de último, pero este pégalo al empezar cada proyecto, antes del mensaje 1.

regla para todo el proyecto
Regla para todo este proyecto: esta app es mía o tengo permiso para estudiarla. Úsala solo para entender cómo funciona. Escribe todo el código desde cero y no copies código, logos, textos ni imágenes del original.

Preguntas frecuentes

¿Cuánto me cuesta?

Rea es gratis y de código abierto (licencia MIT). Solo pagas Claude Pro, unos 20 dólares al mes.

¿Qué apps puede abrir?

Apps de escritorio hechas con tecnología web (como Notion o Slack), programas de Windows hechos en .NET, páginas web y apps de Android. Para programas más cerrados usa Ghidra o Hopper: si los necesita, Claude te dice cuál instalar.

¿Clona apps enteras?

Todavía no. Va pieza por pieza, y eso es lo que más te sirve: rehaces lo que usas y dejas de pagar por lo que no.

¿Es legal?

Úsalo con apps tuyas o con permiso, para entender cómo funcionan. Los creadores de Rea piden exactamente eso. Esto no es asesoría legal: si vas a vender lo que hagas, consulta a un abogado.

¿Te sale “Permission denied (publickey)” al instalar un plugin?

Usa el link completo del repositorio. Por ejemplo: /plugin marketplace add https://github.com/morluto/rea.git y después el /plugin install normal.
